# Rocket Advance

Emulador de Game Boy Advance para el navegador (motor mGBA), instalable como app.

- Abre la app en Chrome del celular → ⋮ → **Instalar app**.
- Toca **Elegir ROM** y elige tu .gba (o un .zip que la contenga). La ROM queda solo en tu celular; no se sube aquí.
- La partida se respalda sola en el celular, con versiones anteriores. Expórtala de vez en cuando desde ☰ → Exportar partida.

## Actualizar
Al cambiar cualquier archivo, sube también `VERSION` en `sw.js` (ra-v1 → ra-v2) para que los celulares tomen la versión nueva. La partida no se borra al actualizar.

## Créditos
Motor: [mGBA](https://mgba.io) (MPL-2.0), compilado para web por el proyecto [EmulatorJS](https://emulatorjs.org).
